## Структура и совместимость

- `index.html`, `assets/library.css`, `assets/library.js` — каталог и поиск.
- `books/ml-systems/index.html` — оглавление четырёх томов.
- `books/ml-systems/volN/` — главы с прежними текстами и якорями.
- Старые `books/ru/volN/*.html` переводят на новые страницы, сохраняя
  параметры URL и якорь при включённом JavaScript. Без JavaScript доступны
  обычная ссылка и meta refresh.
- Изображения, CSS и шрифты сохраняют прежние адреса.
- Старые якоря главной `#vol1`–`#vol4` ведут в оглавление книги.

Чтобы добавить книгу, создайте её раздел в `books/`, добавьте настоящую
карточку `data-book` в каталог и обновите число изданий. Поиск учитывает
видимый текст карточки и дополнительные ключевые слова `data-search`.
Внешние зависимости для работы сайта не нужны.

## Проверка

`node --test tests/library.test.cjs` проверяет перенос URL и поиск.
`python3 tests/catalog-browser.py URL` проверяет поиск в настоящем браузере
через уже установленный `agent-browser`; запуск требует этого инструмента.
